# 2GIS Phone Scraper

Скрипт для автоматизированного сбора номеров телефонов заведений из 2GIS через официальный Places API (Catalog API 3.0).
Скрипт очищает номера от всех лишних символов (скобки, плюсы, тире, пробелы) и сохраняет их единым списком, исключая дубликаты.

## Функционал

- Загрузка данных по городу и нескольким категориям.
- Автоматическая обработка пагинации с защитным пределом от зацикливания.
- Полная очистка номеров до чистого цифрового формата (например, `77011234567`) с отбраковкой заведомо некорректных значений.
- Устойчивость к сетевым сбоям, лимиту запросов (429) и временным ошибкам сервера (5xx): ограниченное число повторов с нарастающей задержкой.
- Промежуточное сохранение прогресса после каждой страницы — при аварийном завершении процесса теряется не более одной последней страницы.
- Безопасное прерывание работы (`Ctrl+C`) с сохранением всех уже собранных данных.
- Управление через `config.json` или аргументы командной строки.

## Установка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/YOUR_USERNAME/2gis-phone-scraper.git
cd 2gis-phone-scraper
```

2. (Опционально, но рекомендуется) создайте виртуальное окружение:

```bash
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Скопируйте шаблон конфигурации и заполните его своими данными:

```bash
cp config.json.template config.json
```

Откройте `config.json` и укажите:

```json
{
  "api_key": "ВАШ_КЛЮЧ_2GIS_API",
  "city": "Алматы",
  "categories": [
    "Рестораны",
    "Кафе",
    "Салоны красоты"
  ],
  "output_file": "phones_list.txt"
}
```

API-ключ 2GIS Catalog API можно получить в [личном кабинете разработчика 2GIS](https://dev.2gis.com/).

> `config.json` уже добавлен в `.gitignore` — ваш ключ не попадёт в git.

## Использование

Запуск с настройками из `config.json`:

```bash
python main.py
```

Запуск с другим путём к конфигу:

```bash
python main.py -c path/to/other_config.json
```

Переопределение отдельных параметров через CLI (имеет приоритет над `config.json`):

```bash
python main.py -k ВАШ_КЛЮЧ -t "Астана" -cat Рестораны Кафе -o astana_phones.txt
```

Доступные флаги:

| Флаг | Описание |
|---|---|
| `-c`, `--config` | Путь к конфигурационному файлу (по умолчанию `config.json`) |
| `-k`, `--api_key` | API-ключ 2GIS |
| `-t`, `--city` | Город для поиска |
| `-o`, `--output` | Имя выходного файла |
| `-cat`, `--categories` | Список категорий через пробел |

## Результат

Итоговый файл (по умолчанию `phones_list.txt`) содержит по одному уникальному номеру на строку в чистом цифровом формате:

```
77011234567
77022345678
...
```

## Логи

Ход выполнения пишется одновременно в консоль и в файл `app.log` в рабочей директории.

## Остановка и восстановление

- `Ctrl+C` останавливает сбор и сохраняет всё, что было собрано на момент прерывания.
- Скрипт также сохраняет промежуточный прогресс после каждой обработанной страницы, поэтому при неожиданном завершении процесса (сбой сети, перезагрузка и т.п.) теряется не более одной последней страницы данных.

## Ограничения и добросовестное использование

Учитывайте условия использования 2GIS Catalog API и лимиты вашего тарифа/ключа — скрипт соблюдает паузу между запросами и повторяет запросы с задержкой при получении кода 429, но не обходит лимиты API.
